# MVP AIPPRA — Sistema de Gestão de Estoque Consignado

Sistema web desenvolvido como Produto Mínimo Viável (MVP) para a **Associação de Apoio aos Pequenos Produtores Rurais e Artesãos de Araçagi (AIPPRA)**.

## 🛠️ Pilha Tecnológica
* **Backend:** Java 21 (LTS) com Spring Boot 3.2.x
* **Persistência:** Spring Data JPA / Hibernate
* **Banco de Dados:** PostgreSQL
* **Segurança:** Spring Security (com criptografia bcrypt)
